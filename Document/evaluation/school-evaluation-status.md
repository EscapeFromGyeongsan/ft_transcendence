# School Evaluation Status

## 1. 확인한 자료와 확인하지 못한 자료

- 확인: 첨부된 **ft_transcendence v21.1 subject**. 쪽수는 문서에 인쇄된 번호다. 보관 사본: [원문 PDF](../../en.subject.pdf).
- 미확인: 해당 캠퍼스의 현재 프로젝트 배정 버전·최신 evaluation sheet·로컬 평가 안내. 현재 작업 공간에는 제공되지 않았다.
- 따라서 아래는 **v21.1 원문과의 대조 결과**이며, 학교 최신 평가표 확인을 완료했다는 뜻이 아니다. 공개된 타인의 평가표로 대체하지 않는다.

## 2. 표현 규칙

학교 최신 Evaluation Sheet가 확인되기 전까지:

- v21.1 기준 확인
- 학교 기준 미확인
- 공식 통과 표현 금지

## 3. 항목별 상태

항목별 학교 평가표 확인 상태는 `mandatory-checklist.md`와 `module-matrix.md`의 "학교 평가표" 열에 기록한다.
